# BURY RICH AI SHORTFORM STUDIO

**버리리치에셋플러스** — AI 기반 소상공인 홍보 숏폼 자동 제작 및 인기 콘텐츠 벤치마킹 플랫폼 (V1.0)

스마트폰으로 촬영한 원본 영상을 올리면 서버가 영상을 분석해 좋은 장면을 고르고,
후킹 문구·자막·로고·연락처 엔딩을 넣은 **1080×1920 세로형 MP4 숏폼**(15/30/45/60초)을 자동으로 만듭니다.

## V1.0 기능
- 고객: 회원가입/로그인, 영상·사진 여러 개 업로드(진행률 표시), 사업장 정보·목적·연령·분위기·스타일·길이·강조 문구·참고 링크·로고 입력, 제작 진행률, 완성 영상 재생·저장, SNS 문구 복사, 수정 요청, 평가, 원본 삭제 요청, 음성 입력
- 영상 분석: 밝기·선명도·흔들림·움직임·장면 전환·중복 장면·피사체 위치, 불량 구간 제외, 추가 촬영 안내, 음성 인식
- 자동 편집(FFmpeg): 핵심 장면 선택·재배치, 9:16 피사체 중심 크롭, 색보정, 확대/축소, 슬로모션, 컷/페이드 전환, 후킹·장면·음성 자막, 로고·주소·연락처 엔딩, 상업용 배경음악 + 음성 자동 더킹, 음량 정규화, H.264 MP4
- 15가지 편집 스타일, 같은 원본으로 3가지 스타일 동시 제작
- 벤치마킹: 참고 영상/링크/수치(출처 표시) 등록, 참고 영상 편집 패턴 자동 측정, YouTube API 조회(키 설정 시), 업종별 패턴 자동 적용
- 운영자: 현황, 주문·검수·승인 전달, 문구/자막 수정 재렌더링(버전 보존), 대리 접수, 결제 기록, 고객별 수익성, 원가(실측/추정 구분), 비용 한도·승인, 작업 재실행, 상품·가격, 음원 라이선스 관리, 시스템 상태
- 운영 자동화: 작업 대기열 + 백그라운드 워커, 자동 재시도, 매일 DB 백업, 보관 기간 지난 원본 정리, 텔레그램 알림(설정 시)

## 실행
```bash
# 필요: Python 3.12+, ffmpeg, fonts-nanum
pip install -r requirements.txt
cp .env.example .env   # 값 수정
ADMIN_PASSWORD=비밀번호 uvicorn app.main:app --port 8000
python -m app.worker   # 다른 창에서
```
Docker: `docker compose up -d` / 클라우드: Railway(Dockerfile 자동 인식)
