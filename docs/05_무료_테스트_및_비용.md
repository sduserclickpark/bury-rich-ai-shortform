## 1. 무료로 테스트하는 방법 (추천: GitHub Codespaces)

GitHub 계정만 있으면 **결제 수단 없이** 클라우드 컴퓨터를 잠시 빌려 프로그램을 실행해 볼 수 있습니다.
개인 무료 계정은 매월 무료 사용량(약 120 코어·시간, 저장 15GB — 4코어 기준 약 30시간)이 주어지며, 다 쓰면 멈출 뿐 결제되지 않습니다(결제 수단을 등록하지 않은 경우).

| 장점 | 단점 |
|---|---|
| 비용 0원, 카드 등록 불필요 | 테스트 전용: 쓰지 않으면 30분 후 자동 정지, 주소가 바뀔 수 있음 |
| 실제 영상 업로드·제작·재생까지 전부 확인 가능 | 고객에게 줄 정식 서비스 주소로는 부적합 |
| 저장소에 설정 파일 포함(자동 설치·자동 실행) | 휴대폰 화면에서 설정 화면이 다소 작음 |

### 휴대폰으로 실행하는 순서
1. 크롬으로 `github.com/sduserclickpark/bury-rich-ai-shortform` 접속 (⋮ → "데스크톱 사이트" 체크 권장)
2. 초록색 **<> Code** 버튼 → **Codespaces** 탭 → **"Create codespace on main"**
3. 처음 한 번은 설치에 5~10분 걸립니다(ffmpeg, 글꼴, 프로그램 자동 설치 후 서버 자동 시작)
4. 화면 아래쪽 **PORTS(포트)** 탭 → 8000번 "숏폼 스튜디오" 줄의 🌐(지구본) 아이콘 → 새 창에서 운영자 화면 열림
5. 로그인: `admin@test.local` / `test1234!` (테스트 전용 계정)
6. 현황 → "고객 영상 대신 접수하기" → 휴대폰 갤러리의 실제 매장 영상 선택 → 작업 탭에서 진행률 확인 → 완성 영상 재생
7. 테스트가 끝나면 github.com/codespaces 에서 해당 Codespace **⋮ → Stop** (무료 시간 절약), 필요 없으면 **Delete**

※ 테스트 주소는 기본적으로 본인 GitHub 로그인으로만 열립니다(외부 공개 아님).
※ 화면이 멈춘 것처럼 보이면 PORTS 탭이 안 보일 때가 있습니다: 왼쪽 위 ☰ → View → Open View → Ports

### 다른 무료 방법 검토
| 방법 | 평가 |
|---|---|
| Hugging Face Spaces (무료 CPU) | 가능하지만 재시작 시 데이터 삭제, 기본 공개 설정, 포트 변경 필요 → 비추천 |
| Render 무료 요금제 | 메모리 512MB·저장공간 없음·잠자기 → 영상 편집에 부족, 비추천 |
| Railway 체험 크레딧 | 가입 시 1회성 소액 크레딧이 제공될 수 있으나 조건 변동이 잦음 → 가입 전 확인 필요 |
| 휴대폰에서 직접 실행(Termux) | 설치가 복잡하고 성능 부족 → 비추천 |

## 2. Railway 서버 이용료 (추정)

Railway는 "기본료 + 실제 사용량" 방식입니다. Hobby 요금제는 월 $5이며 $5어치 사용량이 포함되어, **사용량이 $5 이하면 월 $5만 냅니다.**

알려진 단가(확인 필요): 메모리 1GB·월 약 $10, CPU 1개·월 약 $20, 저장공간 1GB·월 약 $0.15, 데이터 전송 1GB 약 $0.05

| 항목 (월 100편 가정) | 사용량 추정 | 금액 |
|---|---|---|
| 서버 상시 대기 메모리 (웹+워커+음성인식 모델) | 약 0.6~0.8GB | $6~8 |
| 대기 CPU | 거의 0 | $0.5 이하 |
| 영상 렌더링 CPU (편당 약 1분 × 4코어) | 약 7 코어·시간 | 약 $0.2 |
| 저장공간 (원본 90일 보관 시) | 10~30GB | $1.5~4.5 |
| 데이터 전송 (업로드 무료, 고객 재생·다운로드) | 약 10GB | 약 $0.5 |

비용 줄이는 법: 원본 보관 기간 단축(관리 → 비용 한도 설정 → 원본 보관 기간), 음성 인식 끄기(`WHISPER_MODEL` 비움, 메모리 약 0.3GB 절약)

## 3. AI API 예상 비용 (Claude — 선택 기능)

영상 1편당 1회 호출: 장면 사진 최대 8장 + 사업장 정보 → 장면 설명·후킹 문구·자막·해시태그 작성
예상 사용량: 입력 약 4,000토큰, 출력(생각 과정 포함) 약 3,000토큰

| 모델 | 단가 (100만 토큰당 입력/출력) | 1편당 | 월 100편 |
|---|---|---|---|
| Claude Opus 5.5 (현재 기본 설정) | $4 / $20 | 약 $0.08 (약 110원) | 약 11,000원 |
| Claude Sonnet 5.5 | $2 / $10 | 약 $0.04 (약 55원) | 약 5,500원 |
| Claude Haiku 5.5 | $0.10 / $0.50 | 약 $0.002 (약 3원) | 약 300원 |

- 모델은 환경변수 `CLAUDE_MODEL` 하나로 바꿀 수 있습니다. 문구 품질과 비용 중 어느 쪽을 우선할지는 운영자 결정 사항입니다(실제 영상으로 비교 테스트 후 결정 권장).
- 관리자 화면의 비용 한도(월 AI 한도, 1편 한도)를 넘으면 자동으로 멈추고 승인을 기다립니다.
- YouTube Data API: 무료(하루 할당량 안에서) / 텔레그램 알림: 무료 / 음성 인식: 무료(서버 메모리 사용)
