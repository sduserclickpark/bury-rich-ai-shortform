## 테스트 중 발견·수정한 문제
1. 음성 인식 단계가 영상 분석 결과를 지워 '분석 전'으로 표시되던 문제 → 수정
2. 화면 속 움직임을 카메라 흔들림으로 잘못 판정하던 문제 → 불규칙한 떨림만 흔들림으로 판정하도록 수정
3. 같은 자막이 반복되던 문제 / 원본이 짧은 장면이 지나치게 느려지던 문제 → 수정
4. 확대·축소 효과 필터 오류 → 수정
