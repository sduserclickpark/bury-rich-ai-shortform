# BURY RICH AI SHORTFORM STUDIO — 시스템 구조 및 실현 가능성 검토 보고서 (V1.0)

작성일: 2026-11-24 · 대상: 버리리치에셋플러스 운영자

---

## 1. 결론 요약

- **실현 가능합니다.** 원본 영상 업로드 → AI 분석 → 자동 편집 → 30초 세로형(1080×1920) MP4 출력까지 실제로 동작하는 V1.0을 만들었고 테스트를 통과했습니다.
- **스마트폰만으로 운영 가능합니다.** 프로그램은 클라우드 서버에서 돌아가고, 운영자는 휴대폰 크롬 브라우저(홈 화면 앱으로 설치 가능)로 모든 업무를 처리합니다.
- **최소 운영비는 월 1~3만 원 수준**(초기, 월 100편 이하)으로 시작할 수 있습니다. 유료 AI(Claude)를 켜도 영상 1편당 원가는 약 150~400원으로 추정됩니다.
- 처음에는 **무료 기능만으로도** 영상 제작이 됩니다. 유료 API는 승인해 주실 때 하나씩 연결합니다.

## 2. 전체 시스템 구조

```
[고객 휴대폰]          [운영자 휴대폰]
     │  웹 브라우저(앱처럼 설치)  │
     └──────────┬───────────────┘
                ▼
   ┌─────────── 클라우드 서버 (컨테이너 1개) ───────────┐
   │ 웹 서버 (화면 + API)                               │
   │   · 회원/주문/업로드/검수/결제기록/벤치마킹 관리      │
   │ 작업 대기열 (DB의 jobs 표)                          │
   │ 백그라운드 워커 (휴대폰을 꺼도 계속 실행)             │
   │   · 영상 분석 → 음성 인식 → 기획 → FFmpeg 편집 → MP4 │
   │   · 실패 시 자동 재시도(3회), 매일 DB 백업            │
   │ 저장 공간 (원본·완성 영상·DB)                        │
   └───────────────────────────────────────────────────┘
                │ (선택 연결)
   Claude API · YouTube Data API · 텔레그램 알림
```

## 3. 기술 구성

| 구분 | 사용 기술 | 비용 | 설명 |
|---|---|---|---|
| 서버 언어 | Python 3.12 + FastAPI | 무료 | 웹 화면과 기능 처리 |
| 영상 편집 | FFmpeg | 무료 | 자르기·세로 변환·색보정·확대축소·자막·음악·MP4 출력 |
| 영상 분석 | OpenCV + NumPy | 무료 | 밝기·선명도·흔들림·장면 전환·중복·피사체 위치 측정 |
| 음성 인식 | faster-whisper (서버 내 실행) | 무료 | 한국어 음성을 자막으로 (서버 CPU 사용) |
| 홍보 문구 | ① 규칙 기반(무료) ② Claude API(유료 선택) | 0원 / 약 50~150원/편 | ②는 장면 사진을 보고 내용 인식 + 문구 작성 |
| 데이터베이스 | SQLite | 무료 | 초기에 충분. 고객 수천 명 이상이면 PostgreSQL로 교체 |
| 화면 | 모바일 웹(PWA) | 무료 | 앱스토어 등록 없이 홈 화면에 설치 |
| 자막 글꼴 | 나눔스퀘어라운드 | 무료(상업적 이용 가능) | |
| 배포 | Docker + Railway | 월 사용량 과금 | GitHub 연결만으로 자동 배포 |

| AI 음성(TTS) | 내레이션 | V3 | 유료 | **미연동** (대본만 생성) |

## 6. 비용 추정

> 아래 금액은 2026년 11월 기준 공개 요금을 바탕으로 한 **추정치**이며, 각 서비스의 요금 페이지에서 가입 전에 다시 확인해야 합니다. 환율 1달러 = 1,400원 가정.

### 6-1. 초기 개발 비용
- 개발: Claude Code로 진행 → **현재 이용 중인 Claude 구독 외 별도 개발비 없음**
- 도메인(선택): 연 1~3만 원
- 결제 연동(V4): PG 가입비는 업체별 0원~22만 원(프로모션 다수)

### 6-2. 월간 운영 비용 (월 100편 제작 가정)
| 항목 | 추정 금액 | 비고 |
|---|---|---|
| Railway Hobby 요금제 | 약 7,000원($5) | 사용량 $5 포함 |
| 서버 사용량 추가분 | 약 0~15,000원 | 대기 중에는 거의 과금 없음, 렌더링할 때만 CPU 사용 |
| 저장 공간 | 약 2,000~10,000원 | 원본 보관 기간(기본 90일)에 따라 달라짐. GB당 월 약 $0.15 |
| Claude API (켜는 경우) | 약 5,000~15,000원 | 편당 50~150원 × 100편 |
| YouTube / 텔레그램 / 음성인식 | 0원 | |
| **합계** | **약 1만~5만 원** | |

### 6-3. 영상 1편당 제작 원가 (추정)
| 항목 | 금액 |

## 7. 무료로 구현 가능한 기능 / 유료 API가 필요한 기능

**무료 (지금 모두 동작)**
- 영상·사진 업로드, 회원가입, 주문 관리, 진행 상황 확인
- 영상 품질 분석(밝기·선명도·흔들림·중복·불필요 장면), 추가 촬영 안내
- 핵심 장면 추출, 순서 재구성, 장면 길이 조절, 9:16 세로 변환, 피사체 중심 크롭
- 밝기·색 보정, 확대/축소 효과, 슬로모션, 페이드 전환
- 자막 디자인(후킹 문구, 장면 자막, 음성 자막), 로고·주소·연락처 엔딩 화면
- 배경음악 삽입·볼륨 자동 조절(관리자가 등록한 상업용 음원), BPM 박자 맞춤
- 15/30/45/60초, 15가지 스타일, 같은 원본으로 3가지 스타일 동시 제작
- 규칙 기반 후킹 문구·자막·해시태그·SNS 게시글 8종
- 음성 인식 자막(faster-whisper)
- 참고 영상 등록·편집 패턴 자동 측정(컷 수, 평균 컷 길이 등), 업종별 패턴 DB 적용
- 원가·수익성 계산, 비용 한도 초과 시 승인 대기, 실패 작업 재실행, DB 자동 백업

**유료 API가 필요한 기능**
- 장면 속 '무엇'인지 인식(음식/인물/매장 내부 등) + 자연스러운 AI 카피 → Claude API
- (V3) AI 내레이션 음성 → TTS API
- (V4) 카드·정기 결제 → PG사
- (V5) 게시 영상 성과 자동 수집 → 각 플랫폼 공식 API(고객 계정 연결·동의 필요)

## 9. 클라우드 배포 방법 (요약)

1. GitHub 저장소의 개발 브랜치를 main 에 병합 (휴대폰 GitHub 웹에서 가능)
2. railway.com → GitHub로 로그인 → New Project → Deploy from GitHub repo → 저장소 선택
3. Volume(저장 공간) 추가: 마운트 경로 `/data`
4. Variables(환경변수) 입력: `SECRET_KEY`, `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `WHISPER_MODEL=base`
5. Settings → Networking → Generate Domain → 생성된 주소를 휴대폰에서 열고 "홈 화면에 추가"

자세한 화면별 안내: `docs/02_스마트폰_배포_안내.md`

## 10. 솔직한 한계와 주의사항

- **실제 스마트폰 원본 영상으로는 아직 테스트하지 못했습니다.** 개발 환경에서 인터넷 영상 다운로드가 차단되어, FFmpeg로 만든 테스트 영상(정상·어두움·흔들림·흐림·중복 장면 포함)으로 검증했습니다. 배포 후 실제 매장 영상으로 1차 테스트가 필요합니다.
- **음성 인식 모델은 이 개발 환경에서 내려받을 수 없어** 실제 인식은 확인하지 못했습니다(모델 다운로드가 막히면 자막 없이 제작을 계속하도록 처리됨). 배포 서버에서는 최초 1회 자동으로 내려받습니다. 관리자 화면 → 관리 → 시스템 상태에서 작동 여부가 표시됩니다.
- **Docker 이미지는 이 환경에서 빌드 확인을 하지 못했습니다**(빌드 중 패키지 다운로드 차단). Railway가 처음 빌드할 때 오류가 나면 로그를 알려 주시면 바로 고치겠습니다.
- Claude API 연동 코드는 작성했지만 **API 키가 없어 실제 호출은 테스트하지 않았습니다.** 호출이 실패하면 무료 문구로 자동 전환됩니다.
- 인스타그램·틱톡은 공식 API로 타인 인기 영상 통계를 가져올 수 없어 **관리자 수동 입력**으로 운영합니다. 화면에 '관리자 입력'과 'API'가 구분 표시됩니다.
- 조회수 증가·매출 증가를 보장하지 않습니다.
