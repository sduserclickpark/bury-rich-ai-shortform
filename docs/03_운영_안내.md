# 운영 안내 (스마트폰)

## 하루 업무 흐름
1. **현황** 탭: 검수 대기 / 수정 요청 / 실패 작업 숫자 확인 → 숫자를 누르면 해당 목록으로 이동
2. **주문 → 주문 상세**
   - 완성 영상 재생 → 괜찮으면 **"승인·고객 전달"** → 고객 화면에 영상과 SNS 문구가 나타납니다
   - 고치고 싶으면 **"문구·자막 수정 후 다시 만들기"** → 후킹 문구·장면별 자막·자막 크기/위치·길이·밝기·엔딩 정보 수정 → 새 버전 생성(이전 버전 보존)
   - 다른 느낌을 보고 싶으면 **"서로 다른 3가지 스타일로 제작"**
   - 입금 확인 후 **결제 → 입금 확인 기록**
3. 카카오톡으로 영상을 받은 고객은 **현황 → 고객 영상 대신 접수하기**

## 품질 높이는 법
- 주문 상세 → **원본 분석**에서 어두움·흐림·흔들림 구간과 촬영 팁을 확인하고 고객에게 안내
- **벤치마킹** 탭에 업종별 인기 숏폼을 등록할수록 컷 길이·자막 위치·추천 스타일이 자동 반영됩니다
  - 링크 + 확인한 조회수·좋아요(직접 본 숫자만) + 후킹 방식·구성 메모
  - 적법하게 확보한 참고 영상 파일을 올리면 컷 수·평균 컷 길이를 자동 측정
  - 고객이 주문 시 남긴 참고 링크는 '검토 필요'로 들어옵니다 → 확인 후 "사용하기"
- **관리 → 배경음악**: 상업적 이용 가능 음원을 출처·이용조건과 함께 등록(없으면 원본 소리 사용)

## 비용 관리
- **관리 → 비용 한도 설정**: 월 AI 사용료 한도, 1편 원가 한도. 넘을 것 같은 작업은 '승인 필요'로 멈추고 작업 탭에서 승인할 수 있습니다
- **관리 → 고객·수익성**: 고객별 매출·원가·이익

## 상태 설명
| 상태 | 뜻 |
|---|---|
| 접수 | 주문이 들어옴 |
| 제작 중 | 서버가 분석·편집 중 (휴대폰을 꺼도 계속됨) |
| 검수 대기 | 영상 완성, 운영자 확인 필요 (고객에게는 아직 안 보임) |
| 완성 | 고객에게 전달됨 |
| 수정 요청 | 고객이 수정 요청을 남김 |
| 실패 | 3번 시도 후 실패 → 작업 탭에서 "다시 실행" |

## 개인정보·저작권
- 고객 영상은 로그인한 본인과 관리자만 볼 수 있고 외부 공개 링크가 없습니다
- 고객이 원본 삭제를 요청하면 고객 화면 또는 관리자가 삭제 가능, 전달 완료 후 보관 기간(기본 90일)이 지나면 원본 자동 삭제
- 고객 영상은 AI 학습에 쓰지 않습니다(Claude API는 기본적으로 입력 데이터를 학습에 사용하지 않음)
- 인기 숏폼은 '패턴'만 참고하며 영상·음악을 복제하지 않습니다
