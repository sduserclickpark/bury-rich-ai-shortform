# 스마트폰만으로 서버에 올리기 (Railway)

PC 없이 휴대폰 크롬 브라우저로 진행합니다. 약 15분 걸립니다.
※ Railway는 유료 요금제(Hobby, 월 $5 + 사용량)가 필요합니다. 결제 카드 등록은 운영자님이 직접 결정해 주세요.

## 0. 준비 (완료됨)
- main 브랜치 생성 및 기본 브랜치 설정: 2026-11-24 완료
- 서버는 **main 브랜치만** 배포합니다. 개발 브랜치의 변경은 운영자가 Pull Request를 승인(Merge)해야 서버에 반영됩니다.

## 1. Railway 가입
1. railway.com 접속 → "Login" → "Login with GitHub" → 권한 허용
2. 요금제: Hobby 선택(카드 등록)

## 2. 프로젝트 만들기
1. "New Project" → "Deploy from GitHub repo" → `bury-rich-ai-shortform` 선택
2. 서비스 → Settings → Source → Branch 를 `main` 으로 지정
3. 자동으로 `Dockerfile`을 찾아 빌드를 시작합니다(5~10분).

## 3. 저장 공간(Volume) 연결 — 꼭 해야 영상·DB가 지워지지 않습니다
1. 프로젝트 화면에서 서비스(상자)를 길게 누르거나 "+ New" → "Volume"
2. 연결할 서비스 선택, Mount path: `/data`

## 4. 환경변수(Variables) 입력
서비스 → "Variables" → "New Variable" 로 하나씩 입력:

| 이름 | 값 |
|---|---|
| `SECRET_KEY` | 아무도 모르는 긴 문자열 (영문+숫자 **32자 이상**, 없거나 짧으면 서버가 시작되지 않음) |
| `ADMIN_EMAIL` | 관리자 로그인 이메일 |
| `ADMIN_PASSWORD` | 관리자 비밀번호(8자 이상, 없으면 서버가 시작되지 않음) |
| `WHISPER_MODEL` | `base` |
| `APP_ENV` | `production` |

(선택) 나중에 추가: `ANTHROPIC_API_KEY`, `YOUTUBE_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`
※ API 키는 이곳(서버 환경변수)에만 넣습니다. 채팅이나 코드에 붙여 넣지 마세요.

## 5. 주소 만들기
서비스 → "Settings" → "Networking" → "Generate Domain" → `xxxx.up.railway.app` 주소가 생깁니다.

## 6. 휴대폰에서 확인
1. 생성된 주소 접속 → 관리자 이메일/비밀번호로 로그인 → 운영자 화면이 나오면 성공
2. 크롬 메뉴(⋮) → "홈 화면에 추가" → 앱처럼 사용
3. 관리 → 시스템 상태에서 "자막 글꼴: 정상", 저장 공간 확인
4. 현황 → "고객 영상 대신 접수하기"로 실제 매장 영상 1개를 올려 테스트
5. 작업 탭에서 진행률 확인 → 완료되면 주문 → 영상 재생 → 저장

## 문제가 생기면
- Railway 서비스 → "Deployments" → 실패한 배포 → "View Logs" 화면을 캡처해서 Claude에게 보여 주세요.
- 이전 버전으로 되돌리기: Deployments 목록에서 정상이던 배포의 "⋮" → "Redeploy"

## 텔레그램 알림 켜기 (무료, 선택)
1. 텔레그램에서 `@BotFather` 검색 → `/newbot` → 이름 입력 → 받은 토큰을 `TELEGRAM_BOT_TOKEN` 에 입력
2. 만든 봇에게 아무 메시지나 보낸 뒤, 크롬에서 `https://api.telegram.org/bot<토큰>/getUpdates` 접속 → `"chat":{"id":숫자` 의 숫자를 `TELEGRAM_CHAT_ID` 에 입력
